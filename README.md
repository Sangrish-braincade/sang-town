# sang-town

An explorable 3D portfolio: a small, hand-built city block you walk around in third person.
A few buildings on the street are my projects; walk in and something happens. Toggle day/night,
or use "read as a page" (top-right) for the plain version.

Built with Three.js and Vite.

```bash
npm install
npm run dev
```

Character models and animations are CC0 packs by [Quaternius](https://quaternius.com) and
[Kenney](https://kenney.nl).
